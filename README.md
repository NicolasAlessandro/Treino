# Treino Nicolas (PWA)

## Hospedar no GitHub Pages
1. Crie um repositório (ex.: `treino`) e envie TODOS estes arquivos para a raiz.
2. Settings > Pages > Source: "Deploy from a branch" > branch `main` / pasta `/ (root)` > Save.
3. Aguarde ~1 min e abra `https://SEU-USUARIO.github.io/treino/` no celular.

## Instalar
- iPhone: Safari > Compartilhar > Adicionar à Tela de Início.
- Android: Chrome > menu > Instalar app.

## Notas
- Marcações, cargas e histórico ficam no localStorage do aparelho (não sincronizam). Exporte o CSV em Evolução de tempos em tempos.
- Ao alterar o app, mude `CACHE` em `sw.js` (treino-v1 > treino-v2) para forçar a atualização.
